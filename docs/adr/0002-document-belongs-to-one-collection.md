# A Document belongs to exactly one Collection

A Document cannot appear in more than one Collection. When content is needed in two places, users ask across both Collections (a chat may span several) or upload it twice. Allowing shared Documents would make access depend on any of several Collections, complicate deletion ("delete from here, or everywhere?"), and blur which Owner controls the content. Keeping one Collection per Document lets every Chunk carry a single Collection identity that retrieval filters on.
