# Extraction test files

Documents used to choose and check Docent's PDF and Word extraction (ADR 0011). The PDFs and the two templates below are real-world documents, kept unchanged; they are also in the Demo Collection. `holiday-guidance.docx` and `staffing-guidance.docx` were built from GOV.UK text with Word's built-in styles, because openly licensed real-world `.docx` files are scarce.
