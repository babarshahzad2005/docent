# Evals

Answer quality for Docent is measured here, not judged by feel.

This directory will hold the Eval Set (questions about the Demo Collection, each with its expected passages or marked unanswerable) and the harness that scores retrieval hit rate, faithfulness, and decline rate. It runs in CI on every pull request from milestone M2 onward. See [docs/PRD.md](../docs/PRD.md) for the targets.
