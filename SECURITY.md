# Security Policy

Docent handles user documents and enforces per-collection permissions, so security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Report privately through GitHub's [private vulnerability reporting](https://github.com/babarshahzad2005/docent/security/advisories/new).

Include steps to reproduce and the impact you observed. You can expect an initial response within 7 days.

## In scope

- Access to documents or passages from a collection you are not a member of
- Bypassing authentication, roles, rate limits, or public-link expiry
- Prompt injection that causes actions or data disclosure beyond the asked collection
- Exposure of API keys or other secrets
